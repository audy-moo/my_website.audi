# CV Digital - Audi Kristina Panjaitan

Website CV statis menggunakan HTML, CSS, dan JavaScript.

## Menjalankan secara lokal
1. Pastikan `index.html`, `style.css`, `script.js`, dan folder `assets` berada dalam satu folder.
2. Pastikan foto profil bernama `profile.jpg` berada di `assets/`.
3. Buka `index.html` di browser.

## GitHub Pages
1. Upload seluruh isi folder ini ke repository GitHub.
2. Buka Settings > Pages.
3. Pada Build and deployment pilih Deploy from a branch.
4. Pilih branch `main`, folder `/ (root)`, lalu Save.
5. Tunggu proses deployment dan buka URL GitHub Pages yang diberikan.

## Catatan
Ini simulasi login sisi-klien untuk demonstrasi. Kredensial disimpan di JavaScript dan ditampilkan di halaman login, sehingga bukan autentikasi aman untuk data rahasia.
